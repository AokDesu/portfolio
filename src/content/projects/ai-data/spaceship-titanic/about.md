# Spaceship Titanic EDA

An in-depth exploratory data analysis of Kaggle's Spaceship Titanic dataset, uncovering 12 key empirical findings on passenger survival factors during spacetime anomaly transport. The analysis features reproducible Python scripts, detailed statistical visualisations, and a structured walkthrough notebook examining confounding demographic and behavioral features.

## Stack
- **Language**: Python 3
- **Data & Statistics**: Pandas, NumPy
- **Visualization**: Matplotlib, Seaborn
- **Environment**: Jupyter Notebook, Kaggle CLI
